# Especificações de Hardware

Este diretório centraliza as especificações técnicas, pinagens e arquiteturas físicas das placas de desenvolvimento e sensores sob investigação para o projeto de rastreamento da EMAP.

## Placas de Desenvolvimento (Dev Boards)

*   **[LILYGO TTGO LoRa32 V2.1 & T3 V1.6.1](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/hardware/lilygo_lora32.md)**: ESP32 + LoRa SX1276 com tela OLED e leitor SD.
*   **[Seeed Studio XIAO nRF54L15](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/hardware/seeed_xiao_nrf54l15.md)**: Placa ultra compacta baseada em Arm Cortex-M33 + RISC-V com Bluetooth 6.0.
*   **[LILYGO TTGO Meshtastic T-Beam V1.2](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/hardware/lilygo_t_beam.md)**: ESP32 + LoRa SX1276/SX1278 com GPS integrado e suporte a rede Mesh.
*   **[LILYGO TTGO SoftRF T-Echo](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/hardware/lilygo_t_echo.md)**: nRF52840 + LoRa SX1262 de alta eficiência com e-paper e GPS.
*   **[LILYGO TTGO T-SIM7000G](lilygo_t_sim7000g.md)**: ESP32-WROVER-B + modem SIM7000G (LTE CAT-M / NB-IoT) com GNSS integrado, para rastreamento sem gateway.
