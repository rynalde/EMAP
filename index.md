# EMAP Port Area Tracking System

Bem-vindo ao repositório de conhecimento (OKF Knowledge Bundle) do projeto de monitoramento em tempo real da área portuária da EMAP (Empresa Maranhense de Administração Portuária), desenvolvido pelo IFMA Campus Santa Inês.

Este repositório está organizado utilizando o **Google Open Knowledge Format (OKF)** para permitir que tanto desenvolvedores quanto agentes de IA consigam ler, navegar e expandir a base de conhecimento de forma estruturada.

## Estrutura de Diretórios

O conhecimento deste projeto está segmentado nos seguintes tópicos:

*   **[Objectives](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/objectives/index.md)**: Objetivos, escopo e justificativa do sistema de rastreamento.
*   **[Organization](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/organization/index.md)**: Cronograma (timeline) de desenvolvimento, recursos, e estrutura da equipe executora.
*   **[Hardware](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/hardware/index.md)**: Especificações técnicas detalhadas, diagramas de pinagem e gerenciamento de energia das placas de desenvolvimento.
*   **[Research](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/research/index.md)**: Referências bibliográficas acadêmicas e links úteis de APIs/firmwares.
*   **[Experiments](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/experiments/index.md)**: Histórico, relatórios de testes de comunicação (LoRa) e posicionamento indoor.
*   **[Software](file:///Users/rynalde/Documents/GitHub/EMAP/EMAP/software/index.md)**: Arquitetura do sistema de medição, esquemas do banco de dados e especificações dos dashboards de KPIs.
